## Getting Started

To contribute:

1. **Fork** the repository.  
2. **Clone** your fork:  
   ```bash
   git clone https://github.com/JoseLuis-Figueroa/FRDM-MCXC444-GPIO-Driver.git
   cd FRDM-MCXC444-GPIO-Driver
   ```
3. **Create a new branch** for your work:
   ```bash
   git checkout -b your-feature-branch
   ```
